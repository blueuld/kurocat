# KuroCat v5.2.1 完整用法

> 版本：5.2.1（自定义构建，含打字统计 / 悬停让位 / 实时轮廓命中 / 自更新）
> 安装位置：`E:\3_program\Portable\KuroCat\`
> 配置目录：`%APPDATA%\kuro-cat-pet\`
> 更新于：2026-11-26

---

## 1. 它是什么

一只常驻桌面的小猫（或鲸鱼娘），跟着你敲键盘的动作动爪、动尾巴，并把「今天打了多少字」显示在屏幕上。当前版本在我自己编译的构建上做了四项增强：

| 增强 | 作用 |
|---|---|
| 打字统计 | 精确统计当天实际录入的字数，并可显示每分钟速度 |
| 悬停让位 | 鼠标停在它身上超过设定时间，自动淡化并让出下面的窗口 |
| 实时轮廓命中 | 判定"鼠标是否在它身上"改为读当前帧像素，换任何角色都自动适配 |
| 自更新 | 应用内「检查更新」直接指向本仓库，一键升级且保留配置 |

## 2. 安装与启动

### 2.1 目录结构

```
E:\3_program\Portable\KuroCat\
  ├─ KuroCat.exe               主程序（约 4.7 MB）
  ├─ KuroCat.exe.orig-5.1.2    官方原版备份（可删）
  └─ uninstall.exe             卸载程序
```

### 2.2 启动

- 双击 `KuroCat.exe`，或
- 开始菜单搜索 `KuroCat`，或
- 已开启开机自启时，登录后自动出现

首次启动会出现在**屏幕右下角**。找不到它时，右键菜单里有一项「重置位置到右下角」。

### 2.3 退出

右键小猫（或托盘图标）→ 「退出」。**只关窗口不会退出**，它是常驻进程。

### 2.4 开机自启

右键菜单 →「键盘·OBS·系统」页 →「开机自动启动」打开即可，等价于写入：

```
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
  KuroCat = "E:\3_program\Portable\KuroCat\KuroCat.exe"
```

> 挪动程序目录后必须重开一次自启，否则路径失效会导致开机不启动且不报错。

| 操作 | 效果 |

| 左键点它 | 摸头（会有反应和呼噜声，声音可关） |

### 关于「锁定鼠标穿透」

开启后整个窗口不接收鼠标，点击会穿透到下面的程序——**这时无法摸头、也无法拖动**。适合"只想看，不想被挡"的场景。

- 按住 `Alt` 可临时接管鼠标，点一下即可拖动或开菜单
- 或者点提示条右侧的「解锁」按钮
- 注意：开启穿透后，左侧那句「按住 Alt 或点右侧解锁」的提示条会常驻显示

## 5. 打字统计

### 5.1 显示什么

猫身上会浮出一个半透明胶囊标签，位置由「字数统计位置」决定（默认在键盘下方居中）：

```
今日 1,248 字                     ← 平时
今日 1,248 字 · 87 字/分          ← 正在打字时
```

速度算法：最近 **10 秒**滑动窗口折算每分钟；起步阶段分母不低于 2 秒（避免刚敲两下显示几百）；**停手超过 4 秒**速度归零。

### 5.2 统计口径（重要）

统计的是**实际上屏的字符数**，不是按键次数：

| 情况 | 是否计入 |
|---|---|
| 英文/数字/标点敲一个字 | +1 |
| 中文输入法打拼音 `nihao` | 拼音过程**不计** |
| 拼音上屏「你好」两个字 | **+2**（按实际字数） |
| 退格 / 删除 | **−1**（不会让今天变成负数） |
| 回车、Tab、方向键、F 键、Ctrl+C 等 | 不计 |
| 密码框里输入 | **完全不统计** |
| 粘贴 20 字以上、切换窗口、打开大文档 | 不计（视为换上下文） |
| 超过 4 万字的文档 | 不统计（读取成本过高，主动跳过） |

实现方式是读**焦点输入框的文本长度变化**，三级回退依次尝试：`TextPattern`（现代应用）→ `ValuePattern`（老式编辑框）→ `LegacyIAccessible`（MSAA 兜底）。三级都读不到的应用（部分游戏、少数终端）会自动退回按键计数——在那里英文仍准，中文会偏高。

### 5.3 数据存在哪

| 内容 | 位置 |
|---|---|
| 今日字数与 60 天历史 | 浏览器 localStorage：`kurocat.typing-stats.v1` |
| 标签位置选择 | localStorage：`kurocat.typing-stats.pos` |

**只存数字，不存任何字符内容**，不上传、不写日志。跨天自动清零并把前一天归档，保留 60 天。

选「不显示」只是隐藏标签，**计数照常进行**，切回来数字是对的。

## 6. 悬停让位（淡化）

### 6.1 行为

- 鼠标停在它**身上**超过阈值时间（默认 350 ms）→ 整体淡化到设定透明度（默认 12%），**同时放开鼠标点击**，下面的窗口立刻可操作
- 鼠标移开 → 立即恢复
- **阈值内快速点击仍然能摸头**，不会因为"想摸它结果它躲开"

### 6.2 判定范围

判定"鼠标是否在它身上"读的是**当前帧实际画出来的像素**（每 200 ms 采样一次画布 alpha）：

- 换任何角色（猫、鲸鱼娘、大肥鱼）、改缩放、换姿态（歪头、呼吸、抬头）都自动适配
- 尾巴、头发、伸出的爪子、抬起的手臂都算
- 字数标签和提示条这些浮层也算在内
- 掩码失效（超过 2 秒没更新）时回退到内置几何兜底

### 6.3 三个参数

| 参数 | 范围 | 默认 | 调法 |
|---|---|---|---|
| 悬停淡出 | 开/关 | 开 | 关掉后完全不淡化、整窗按旧规则判定 |
| 悬停多久后让位 | 100–1500 ms | 350 ms | 调大 → 更不容易触发，适合常摸它 |
| 悬停时不透明度 | 5–100% | 12% | 调大 → 淡化更浅（100% 等于不淡化） |

修改即时生效，不需要重启。

### 6.4 和「锁定穿透」的关系

即使开了「锁定鼠标穿透」，悬停淡化**依然生效**——视觉让位和点击接收是两件事。区别只是：锁定时本来就不接收点击，淡化纯粹是为了不挡视线。

## 7. 检查更新

### 7.1 怎么用

右键菜单 →「键盘·OBS·系统」→「检查更新 v5.2.1」

| 结果 | 表现 |
|---|---|
| 有新版本 | 顶部弹「发现新版本 vX.Y.Z」+ 按钮「立即更新」 |
| 已是最新 | 提示「✓ 已是最新版本 v5.2.1」，2.6 秒后自动消失 |
| 检查失败 | 显示错误，可点「打开发布页」手动下载 |

点「立即更新」后：下载 → 校验 SHA-256 → 原地替换 exe → 自动重启。**配置、打字统计、皮肤选择全部保留**。

### 7.2 背后做了什么

- 更新清单来自 Release 资产里的 `latest.json`，走普通重定向，**不消耗 GitHub API 的匿名配额**（每小时 60 次，共享代理出口很容易被限流成 403）
- 下载走系统代理：程序会读 `HKCU\...\Internet Settings` 里的 `ProxyEnable`/`ProxyServer`，有代理就用代理，代理不可达时自动回退直连
- 校验用清单里的 `sha256`，不匹配会拒绝安装

### 7.3 不想自动更新

程序不会后台偷偷升级，只有你点「立即更新」才会。想彻底不检查，就别点那一项；或者直接把 `settings.json` 里的更新检查当作手动操作即可。

## 10. 故障排查

### 10.1 鼠标移上去不淡化

按顺序排查：

1. 「悬停淡出」是否为「开」？延迟是否调得过大（比如 1500 ms）？
2. 鼠标是否停在**透明区域**（角色旁边的空白）？那里本来就不该触发
3. 是否正处于拖动状态？（拖动期间不触发）
4. 停留在目标位置**至少 1 秒**再看——采样是 200 ms 一次，判定需要连续命中

开发者排查（需用调试端口启动）：

```bash
cd "E:/3_program/Portable/KuroCat"
WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS="--remote-debugging-port=9222" ./KuroCat.exe
# 另一个终端：
node tools/domcall.mjs "window.__TAURI_INTERNALS__.invoke('get_hit_diag')"
```

输出示例：

```
rx=0.420 ry=0.450 inside=true over=true mask=true maskHit=true size=48 bits=872
```

- `inside=false` → 光标不在窗口内（窗口位置/坐标问题）
- `mask=false` → 前端掩码没送到（回退了几何判定）
- `maskHit=false` → 该点确实被判为透明
- `over=true` 但没淡化 → 检查 `hoverFade` 设置

### 10.2 更新时报「下载文件不完整」

代理不稳定导致大文件断流。重试一次即可；连续失败可手动下载 Release 里的 `KuroCat-<版本>-windows-x64.exe` 直接替换。

### 10.3 检查更新报 403 或网络错误

GitHub API 被限流（每小时 60 次，共享代理 IP 极易触发）。程序已优先走不占配额的清单地址，若仍失败，等几分钟再试，或手动下载。

### 10.4 开了穿透后点不到它

按住 `Alt` 再点，或点提示条右侧「解锁」，或在托盘图标上右键。

### 10.5 找不到窗口

右键托盘图标 →「重置位置到右下角」。若托盘图标也不见了，删掉 `settings.json` 里的 `x`/`y` 两个字段后重启。

### 10.6 想彻底恢复默认

关闭程序，删除 `%APPDATA%\kuro-cat-pet\` 整个目录，重新启动。注意这会一并清掉打字统计历史。

## 11. 已知限制

1. **字数统计依赖可读的输入控件**。游戏自绘输入框、少数终端读不到文本，会退回按键计数，中文会偏高。
2. **实时轮廓采样有 200 ms 间隔**。鼠标极快划过时可能来不及更新，但淡化本身有 100 ms 以上延迟，正常情况下无感。
3. **35% 以下的小缩放下，判定格变粗**（48 格网格对应更多像素），边缘可能有一格左右的误差。
4. **不支持 Linux**（本构建仅 Windows x64）。
5. 角色来自上游项目，部分皮肤在 3D 模式下会以 2D 形象呈现。
